# 計画4: 会社概要・事業・店舗ページ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `/about`、`/business`、`/business/[business]`、`/business/[business]/[venue]` を作る。事実情報（住所・営業時間など）はまだ提供されていないため、**データがある項目だけを表示するテンプレート**にし、情報を `content/` に追加するだけで反映される状態にする。

**Architecture:** 全ページ SSG（`generateStaticParams` + `dynamicParams = false`）。データはすべて `lib/content.ts` 経由。下書き文章（代表挨拶など）は `draft: true` を持ち、**本番（`VERCEL_ENV === "production"`）では非表示、プレビューとローカルでは「下書き」バッジ付きで表示**する。トップで作った演出部品（Reveal、Tilt、SectionEyebrow、横スワイプ）を再利用し、ページ間で世界観を揃える。

**Tech Stack:** 既存（Next.js 16 / motion / Tailwind v4 / zod）

**Spec:** 設計書「2. サイトマップ」「4. デザインシステム（店舗ページのヒーローのみ写真全面）」

---

## コンテンツ追加

- `content/company.json`（新規・`CompanySchema`）: `name`（必須: "遊栄JAPAN株式会社"）、`nameEn`（"YUEI JAPAN Inc."）、任意: `representative`, `established`, `capital`, `address`, `tel`, `employees`, `businessSummary: string[]`, `history: {date, text}[]`, `philosophy?: { title, body }`, `greeting?: { title, body, signature?, draft: boolean }`。
  - 初期値: name/nameEn、`businessSummary` は4事業名、`philosophy` は企業メッセージ（トップと同文、確定済み）、`greeting` は Claude の下書き（`draft: true`）。その他は空。
- `content/businesses/*.json` に追加（任意）: `lead`（事業ページのリード文）、`description`（段落配列）、`services?: {title, body}[]`、`flow?: {step, title, body}[]`（digital 用）。文章はブランドトーンの説明文（事実の主張をしない一般的な説明に留める）。
- `content/venues/**.mdx` に `gallery` を実写で追加（`assets-pipeline/source-map.json` に追記して `pnpm assets:source`）。
  - kingyo: goldfish-bowl, chandelier, parallax-goldfish, parallax-wagara, parallax-champagne ほか `images/kingyo/*`
  - b-club: light-01..03 ＋残りの `images/Bclub/*`
  - c-girl: exterior のみ
  - en: dish-01..03 ＋ `images/En/*` から10枚程度
  - danke: interior-01,02 ＋ `IMG_3174..3176`
  - signage: chimatsushima, peace（eiraku, bansui は写真なし）
- ヘッダー画像: `about-hero`、`business-hero`（Codex 生成・採用）。

## ページ

| ルート | 構成 |
|---|---|
| `/business` | PageHeader（business-hero）→ 4事業の大きなカード（交互レイアウト、PC は Tilt）→ CTA |
| `/business/[business]` | PageHeader（事業の heroImage）→ リード＋説明 → 拠点一覧（nightlife/dining/signage: 写真カード、スマホ横スワイプ・PC グリッド）／ digital: サービス一覧＋制作フロー（スクロールで進むステップ）→ 事業固有 CTA（signage: 広告掲載、digital: 制作相談、その他: 採用） |
| `/business/[business]/[venue]` | 写真全面ヒーロー（スクロールでズームアウト）→ キャッチコピー・本文 → ギャラリー（横スワイプ＋拡大表示）→ 店舗情報（データがある行だけ）→ 公式サイト/SNS ボタン（ある場合）→ 同じ事業の他の拠点 |
| `/about` | PageHeader（about-hero）→ 企業理念 → 代表挨拶（下書きは本番非表示）→ 会社概要テーブル（データがある行のみ）→ 沿革（あれば、タイムライン）→ アクセス（住所があれば Google マップへのリンク） |

事業ページ・店舗ページのパンくず（`BreadcrumbList` 構造化データは計画6）。
