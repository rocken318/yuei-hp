# 計画3: トップページ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 仮トップを本番のトップページに置き換える。スマホでもスクロール（スワイプ）に合わせて画面が動き続ける、先進的でクリーンな体験を作る。

**Architecture:** `app/page.tsx` はサーバーコンポーネントでコンテンツを取得し、`components/sections/home/*` の各セクションに props で渡す。スクロール演出は motion の `useScroll`/`useTransform`（ネイティブスクロールに追従するのでタッチでも動く）。汎用エフェクトは `components/effects/` に1ファイル1エフェクトで置く。reduced-motion ではスクロール連動の値を静止させる（AGENTS.md）。

**Tech Stack:** Next.js 16 / motion 13 / Tailwind v4 / 既存の Reveal・トークン・コンテンツ層

**Spec:** 設計書「2. トップページ構成」「4. ヒーロービジュアル」「モバイル体験」

## 企業メッセージ本文（確定案）

> 国分町の夜から、街の未来へ。
> 人が集い、語らい、笑顔になる場所を。
> 飲食、エンターテインメント、デジタルサイネージ、そしてWeb。
> 私たちは領域を越えて、この街に新しい価値を届けます。

日本語は空白で単語分割できないため、`Intl.Segmenter("ja", { granularity: "word" })` で文節に近い単位に分割する（テスト対象）。
